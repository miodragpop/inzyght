API Reference

All endpoints return JSON. Base URL: /api/v1

Blocks
GET /api/v1/blocks

Latest blocks, paginated. Used by the blocks list page.

Query parameters

startinteger — offset (default 0)
lengthinteger — page size (default 25)
GET /api/v1/blocks/{height}

Block summary by height.

Path parameters

heightinteger — block height
GET /api/v1/blocks/hash/{hash}

Block summary by hash.

Path parameters

hashstring — 64-char block hash
GET /api/v1/blocks/verbose/{hash}

Full block detail including all transactions, coinbase, difficulty, and chain metadata.

Path parameters

hashstring — 64-char block hash
GET /api/v1/blocks/raw/{hash}

Raw block JSON as returned directly by the Ycash node (getblock verbosity=2).

Path parameters

hashstring — 64-char block hash
Transactions
GET /api/v1/transactions

Latest transactions (most recent first).

GET /api/v1/transactions/{hash}

Transaction summary (hash, height, timestamp, coinbase flag).

Path parameters

hashstring — 64-char transaction hash
GET /api/v1/transactions/verbose/{hash}

Full transaction detail including transparent inputs/outputs, Sapling spends/outputs, Sprout joinsplits, confirmations, and fee.

Path parameters

hashstring — 64-char transaction hash
GET /api/v1/transactions/raw/{hash}

Raw transaction JSON as returned directly by the Ycash node (getrawtransaction verbose=1).

Path parameters

hashstring — 64-char transaction hash
Addresses
GET /api/v1/addresses/{address}

Address balance, received, sent, transaction count, and paginated transaction history. Transaction history is returned in chunks — follow next_offset_height to load older transactions.

Path parameters

addressstring — transparent Ycash address

Query parameters

offset_heightinteger — block height cursor for pagination (omit for first page)
Network
GET /api/v1/network/info

Node version, protocol version, connection count, relay fee, and network services.

GET /api/v1/network/blockchain

Chain height, best block hash, difficulty, network hash rate, and value pool balances (transparent, Sapling, Sprout).

GET /api/v1/network/peers

Connected peers with IP, port, version, direction (inbound/outbound), ping, and geolocation (country, city, coordinates).

GET /api/v1/state

Combined snapshot of blockchain info, network info, mempool size, and sync status. Used by the home page dashboard.

Real-time
WS /ws

WebSocket connection for real-time events. The server pushes a JSON message on each new block or transaction confirmed on the network.

Message types

new_blockemitted when a new block is indexed — includes height, hash, tx count, timestamp
new_transactionemitted when a new transaction enters the mempool
